# Running this program
To run this program, navigate to this directory in the terminal and run:

## Windows
$ cd ..
$ pip install -r '.\requirements.txt'
$ cd '.\3D Scene\'

## Linux
$ cd ..
$ pip install -r './requirements.txt'
$ cd './3D Scene'

Then, run:

## Windows
$ python3 '.\Paris Olympics Scene.py'

## Linux
$ python3 './Paris Olympics Scene.py'

# Using this program
The following controls are included:
- Left mouse: X/Y movement
- Middle mouse: Z movement
- Right mouse: Rotation
- S: Start the animation
- F: Stop the animation
- O: Use flat shaders
- P: Use Phong shaders
